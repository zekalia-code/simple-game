# NEON RELIC — corrected source

1. Extract the ZIP file.
2. Keep your PC connected to the internet.
3. Double-click `index.html` to open in Chrome or Edge.
4. Click **START EXPEDITION**.

This version uses a classic script and explicit click listeners, so it does not require JavaScript module support or a local web server. Three.js is downloaded from jsDelivr, so internet access is required.

Controls: WASD/arrows to move; Space to jump. Collect 6 crystals, then approach the portal at the far side of the island before the 90-second timer ends. Drone collisions cost 8 seconds.
